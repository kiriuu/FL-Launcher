# FL Launcher
*A Launcher for FL Studio, developed with AutoHotkey v2*

Instrucions
-
- Download the latest version of **FL-Launcher-x64.zip** or **FL-Launcher-x32.zip** from [*here*](https://github.com/kiriuu/FL-Launcher/releases). To find out which version you need, just go to Windows Settings and check whether your PC is x64 or x32.
- Extract the **ZIP** file
- Open the folder
- Open the file **FL-Launcher.exe**
- Enjoy :)

Notes
-
If the program doesn't automatically detect your FL Studio projects folder, you can change the path at any time by clicking the **"Root Dir"** button in the upper-left corner.

The executable will only run on Windows

Compiled *AutoHotkey* executables **without** a digital certificate often trigger **false positives** (like Win64.dropper or other) on [*VirusTotal*](https://www.virustotal.com/gui/file/023bc0a9afb64433dc57f3011dad2d760f20c2645d6807d80ca0686906e16c57). The project is **100% open-source**, so you can inspect the .ahk code or run it directly via *AutoHotkey*
