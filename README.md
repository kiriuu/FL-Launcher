# FL-Launcher
A Launcher for FL Studio, developed with AutoHotkey v2

It only works with FL Studio 2026. Send me a private message if you want to use the program with another version of FL
ig: kiriiiu_  //  discord: kiriiiu

Developed with the help of Google Gemini

Note on Antivirus Alerts: Compiled AutoHotkey executables without a digital certificate often trigger false positives (like W32.Dropper) on VirusTotal. The project is 100% open-source, so you can inspect the .ahk code or run it directly via AutoHotkey.
