# FL-Launcher
*A Launcher for FL Studio, developed with AutoHotkey v2*

It only works with *FL Studio 2026*. Send me a private message if you want to use this program with another version of FL.

- ig: [**kiriiiu_**](instagram.com/kiriiiu_)

- discord: **kiriiiu**

Instrucions
-
- Download the latest version of **FL-Launcher-x64.exe** or **FL-Launcher-x32.exe** from [*here*](https://github.com/kiriuu/FL-Launcher/releases). To find out which version you need, just go to Windows Settings and check whether your PC is x64 or x32.
- Open the file **.exe**
- Enjoy :)

Note on Antivirus Alerts
-
Compiled *AutoHotkey* executables **without** a digital certificate often trigger **false positives** (like W32.Dropper) on [*VirusTotal*](https://www.virustotal.com/gui/file/3b5a21cf5689e11c3fd0c331c116b762061465015ad12ab8387e432369ab78d1/detection). The project is **100% open-source**, so you can inspect the .ahk code or run it directly via *AutoHotkey*
