# FL Launcher
*A Launcher for FL Studio, developed with AutoHotkey v2*

Instrucions
-
- Download the latest version of **FL-Launcher-x64.zip** or **FL-Launcher-x32.zip** from [*here*](https://github.com/kiriuu/FL-Launcher/releases). To find out which version you need, just go to Windows Settings and check whether your PC is x64 or x32.
- Extract the **ZIP** file
- Open the folder
- Open the file **.exe**
- Enjoy :)

Notes
-
If the program doesn't automatically detect your FL Studio projects folder, you can change the path at any time by clicking the **"Projects"** button in the upper-left corner.

Compiled *AutoHotkey* executables **without** a digital certificate often trigger **false positives** (like W32.Dropper) on [*VirusTotal*](https://www.virustotal.com/gui/file/3b5a21cf5689e11c3fd0c331c116b762061465015ad12ab8387e432369ab78d1/detection). The project is **100% open-source**, so you can inspect the .ahk code or run it directly via *AutoHotkey*
